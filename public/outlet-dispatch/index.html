Product Master links

which master row each product goes into PACT as

Several master rows share a Product Name, so matching by name alone can send PACT the wrong product. Every product on the Ideal Inventory is listed with the master row it will go to; pick a different row once and every future run uses it. Links are kept in this browser — export them to move to another machine.
